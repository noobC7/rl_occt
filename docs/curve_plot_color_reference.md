# 曲线绘图配色参考

基于你提供的 3 张参考图整理。本文档优先保留图片中已经标出的 HEX 颜色代码，并补充适合后续论文曲线图、实验对比图的组合建议。

## 说明

- 颜色主要来自图片底部已经标注的色卡，不是二次采样估计色。
- 第 1 张图中的 `#FFF9E3` 与其下方 RGB 文本 `R:254 G:249 B:230` 存在轻微不一致；本文先保留图片中的 HEX，实际作图时建议以 HEX 为准。
- 白底论文图中，过浅颜色更适合做背景、误差带、阴影区或辅助区域，不建议直接作为很细的主曲线。
- 如果同一张图中曲线超过 4 条，建议同时配合不同线型，如 `-`、`--`、`-.`、`:`，这样区分度会更稳。

## 推荐曲线组合

下面这些组合优先考虑了白底论文图上的可读性和互相区分度。

| 组合名 | 适合曲线数 | 颜色组合 | 使用建议 |
| --- | --- | --- | --- |
| `control_target` | 2 | `#48B3D8`, `#D393AB` | 最稳妥的冷暖对比，适合 Control vs Target |
| `cool_warm_soft` | 2 | `#6EC9C4`, `#FDA871` | 更柔和，适合示意图或综述图 |
| `baseline_improved_oracle` | 3 | `#C2D4D8`, `#48B3D8`, `#FDA871` | 基线用灰蓝，改进方法和重点结果更突出 |
| `balanced_triple` | 3 | `#48B3D8`, `#D393AB`, `#FDA871` | 三条主曲线时最均衡 |
| `paper_quad` | 4 | `#48B3D8`, `#6EC9C4`, `#D393AB`, `#FDA871` | 白底论文图里比较稳，冷暖平衡好 |
| `highlight_quad` | 4 | `#78CDEA`, `#FDDA66`, `#E0A4BD`, `#6EC9C4` | 用黄色做重点曲线时很合适 |
| `high_contrast_five` | 5 | `#48B3D8`, `#6EC9C4`, `#FDDA66`, `#D393AB`, `#D391FF` | 五条曲线仍有较好区分度 |
| `full_six` | 6 | `#48B3D8`, `#6EC9C4`, `#FDDA66`, `#FDA871`, `#D393AB`, `#D391FF` | 最推荐的 6 条主曲线组合 |

## 场景化建议

### 1. 两组方法对比

- 主推荐: `#48B3D8` vs `#D393AB`
- 更柔和: `#6EC9C4` vs `#FDA871`

### 2. 一条基线，多条改进方法

- 基线: `#C2D4D8`
- 主方法: `#48B3D8`
- 强调方法: `#FDA871`
- 补充方法: `#D393AB`

### 3. 需要突出一条“最好结果”

- 其他曲线: `#C2D4D8`, `#78CDEA`, `#ACE0DB`
- 最优结果: `#FDA871` 或 `#FDDA66`

### 4. 误差带或置信区间

- 蓝线配套填充: `#C1E6F6`
- 粉线配套填充: `#F4C8DD`
- 紫线配套填充: `#E2D4EB` 或 `#E3CDF3`
- 暖色线配套填充: `#FCE1CE` 或 `#F8CBAC`

## 最终建议

- 如果后续主要是白底论文曲线图，优先从 `paper_quad` 和 `full_six` 两套开始。
- 如果图里只有两条关键曲线，优先用 `#48B3D8` 和 `#D393AB`。
- 如果还要配误差带，建议线条使用深一些的主色，填充使用同色系浅色，不要让填充颜色比曲线更抢眼。
